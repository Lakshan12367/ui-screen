System rules All three variations share: 128×64 grid · single foreground color · Space Grotesk for display, JetBrains Mono for system text · ROMO wordmark anchors boot and headers.
Visual signatures A · circular dots, organic clusters, breathing
B · square dots, fixed grid, density gradients
C · variable-radius dots, halftone waves, motion
Interaction model Rotary encoder throughout: ROTATE = browse · CLICK = select · LONG PRESS = back. Selected state always inverts (dark fill, light text) so it reads instantly on a yellow LCD.
